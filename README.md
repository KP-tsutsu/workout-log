# ワークアウト記録

体重・体脂肪率とトレーニング実績を記録して、目標までの進捗を見る自分専用の Web アプリ。
Mac でサーバーを立てて、自宅 Wi-Fi 内の iPhone から使う。インターネットには公開していない。

## 使い方

### 1. Mac でサーバーを起動する

Finder で `start.command` をダブルクリック。ターミナルが開いて、iPhone から開く URL が表示される。

```bash
python3 server.py
```

終了するときはターミナルで Control-C。

### 2. iPhone から開く

同じ Wi-Fi に繋がった iPhone の Safari で、表示された URL を開く。

```
http://192.168.0.11:8765/
```

初回だけ、共有ボタン → **ホーム画面に追加** をしておくと、アイコンから全画面で起動できる。

## 画面

| タブ | できること |
|---|---|
| ホーム | 目標までの差と進捗、体組成の推移、トレーニング日数と継続、ランニング集計、種目別の伸び |
| 記録 | その日の体重・体脂肪率と、トレーニング実績の入力 |
| 履歴 | 月カレンダーと一覧。過去の記録の確認・編集・削除 |
| マスタ・設定 | 種目マスタ、目標、Mac との同期、JSON バックアップ |

### 種目マスタが入力を軽くする

種目ごとに「使う入力項目」と「必須項目」「＋−の刻み」「既定値」を決めておける。
記録画面ではその定義どおりの欄だけが出るので、ベンチプレスなら重さ・回数・セット数、
ランニングなら距離・時間、というように毎回必要な分だけ入力すればいい。

値は同じ種目の前回の記録で埋まっているので、変わったところだけ直せば済む。
同じ種目で重量を変えて何本か入れるときは「保存して続ける」を使う。

代表的な種目は最初から入っている。使わないものは編集画面から非表示にできる。

## データの置き場所と守り方

記録の正本は **iPhone のブラウザの中 (IndexedDB)**。加えて、接続できているあいだは
自動で **Mac にスナップショットが送られる** (`data/latest.json` と `data/snapshots/`)。

この二重化には理由がある。ブラウザはデータを接続先の URL ごとに分けて保存するため、
ルーターの再起動などで Mac の IP アドレスが変わると、iPhone からは別のサイト扱いになって
それまでの記録が見えなくなる。そうなった場合は、新しいアドレスで開いたときに
「Mac にバックアップがあります。復元しますか?」と聞かれるので、そこから戻せる。
「マスタ・設定」タブの **Mac から復元** でも同じことができる。

- ルーターで Mac の IP を固定 (DHCP 予約) しておくと、そもそも URL が変わらず快適
- 機種変更や Mac の入れ替えのときは、**JSON で書き出す** でファイルを持ち出す
- `data/` は git 管理から外してある

## この構成の制約

- **オフラインでは開けない。** オフライン動作の仕組み (Service Worker) は HTTPS か
  localhost でしか動かないため、`http://192.168.x.x` では有効にできない。
  ジムでは記録できないので、帰宅後にまとめて入力する運用になる。過去の日付への入力は
  記録画面の日付を戻すだけでできる。
- **Mac が起動してサーバーが動いていないと開けない。**
- 認証は無い。同じ Wi-Fi に繋がっている端末なら誰でもアクセスでき、`/api/backup/latest`
  で記録を読める。自宅ネットワーク内に限る前提の割り切り。

### あとからオフライン対応したくなったら

`sw.js` と `manifest.webmanifest` は最初から入れてあり、`js/app.js` は
`isSecureContext` のときだけ Service Worker を登録する。つまり HTTPS 化
(ローカル証明書の導入) か公開ホスティングへの移設をすれば、コードを触らずに
オフライン動作が有効になる。データは JSON の書き出し/読み込みで引き継げる。

## 構成

```
server.py                静的配信 + バックアップ API (Python 標準ライブラリのみ)
start.command            ダブルクリック起動用
data/                    Mac 側のバックアップ (git 管理外)
index.html               画面の骨格
css/app.css              スタイル (ライト/ダーク両対応)
js/db.js                 IndexedDB とスキーマ、種目プリセット
js/state.js              メモリ上のデータと変更通知
js/sync.js               Mac への自動バックアップと復元
js/util.js               日付・数値・トレーニング指標の計算
js/ui.js                 共通 UI 部品
js/charts.js             SVG のグラフ
js/views/                画面ごとの実装
tools/make_icons.py      アイコン PNG の生成 (描き直すときだけ実行)
```

ビルドは不要。素の ES modules で動くので、ファイルを編集して iPhone で再読み込みすれば反映される。

## サーバーの API

| メソッド | パス | 用途 |
|---|---|---|
| GET | `/api/ping` | 疎通確認 |
| GET | `/api/backup/latest` | 最新スナップショット (無ければ 204) |
| POST | `/api/backup` | スナップショットを保存。直近 30 件を保持 |

ポートを変えたいときは `python3 server.py --port 9000`。
