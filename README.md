# ワークアウト記録

体重・体脂肪率とトレーニング実績を記録して、目標までの進捗を見る自分用の Web アプリ。
GitHub Pages に置き、iPhone のホーム画面から起動して使う。一度開けばオフラインでも動くので、
ジムでもそのまま記録できる。

## 公開先

```
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

初回だけ、iPhone の Safari でこの URL を開いて 共有ボタン → **ホーム画面に追加**。
以降はアイコンから全画面で起動する。

## 画面

| タブ | できること |
|---|---|
| ホーム | 目標までの差と進捗、体組成の推移、トレーニング日数と継続、ランニング集計、種目別の伸び |
| 記録 | その日の体重・体脂肪率と、トレーニング実績の入力 |
| 履歴 | 月カレンダーと一覧。過去の記録の確認・編集・削除 |
| マスタ・設定 | 種目マスタ、目標、バックアップ、アプリの更新 |

### 種目マスタが入力を軽くする

種目ごとに「使う入力項目」と「必須項目」「＋−の刻み」「既定値」を決めておける。
記録画面にはその定義どおりの欄だけが出るので、ベンチプレスなら重さ・回数・セット数、
ランニングなら距離・時間、と毎回必要な分だけ入力すればいい。

値は同じ種目の前回の記録で埋まっているので、変わったところだけ直せば済む。
同じ種目で重量を変えて何本か入れるときは「保存して続ける」を使う。

代表的な種目は最初から入っている。使わないものは編集画面から非表示にできる。

## データの置き場所

記録は **この端末のブラウザの中 (IndexedDB)** にだけ保存され、どこにも送信されない。
GitHub Pages に置いてあるのはアプリのコードだけで、記録はサーバーに一切上がらない。

裏を返すと、**控えは「マスタ・設定」タブの「JSON で書き出す」だけ**。
端末の初期化やブラウザのデータ削除で戻せなくなるので、ときどき書き出しておく。
30 日以上書き出していないとその画面で警告が出る。

書き出したファイルは iPhone の「ファイル」アプリに保存される。iCloud Drive に入れておけば、
機種変更のときも「JSON から読み込む」でそのまま戻せる。

## 更新のしかた

ファイルを編集して push すると、GitHub Pages に反映される。

```bash
git add -A && git commit -m "変更内容" && git push
```

iPhone 側はオフライン用にアプリ本体をキャッシュしているため、すぐには新しくならないことがある。
その場合は「マスタ・設定」タブの **アプリを最新にする** を押す。キャッシュを捨てて取り直すだけで、
記録は消えない。

大きく作り替えたときは `sw.js` の `VERSION` を上げると、全端末で古いキャッシュが破棄される。

### 手元で確認してから push したいとき

```bash
python3 server.py
```

`http://localhost:8765/` が開ける。localhost は HTTPS 扱いになるので、オフライン動作もここで試せる。
`start.command` をダブルクリックしても同じ。このサーバーは確認用で、本番には関係しない。

## 公開範囲について

- GitHub の無料プランでは、Pages を使うにはリポジトリを Public にする必要がある
  (Private にできるのは GitHub Pro 以上)。つまり **アプリのコードは誰でも読める**
- 公開された URL も、知っていれば誰でも開ける。ただし開いても中身は空のアプリで、
  **記録は端末の中にしかないので他人には見えない**
- `robots.txt` と `noindex` で検索結果には出ないようにしてある
- リポジトリ名を推測されにくい文字列にしておくと、URL に偶然たどり着かれることもまず無い

## 構成

```
index.html               画面の骨格
css/app.css              スタイル (ライト/ダーク両対応)
js/db.js                 IndexedDB とスキーマ、種目プリセット
js/state.js              メモリ上のデータと変更通知
js/util.js               日付・数値・トレーニング指標の計算
js/ui.js                 共通 UI 部品
js/charts.js             SVG のグラフ
js/views/                画面ごとの実装
sw.js                    オフライン用のキャッシュ
manifest.webmanifest     ホーム画面に追加したときの見た目
tools/make_icons.py      アイコン PNG の生成 (描き直すときだけ実行)
server.py, start.command ローカル確認用 (本番では使わない)
.nojekyll                GitHub Pages に Jekyll 処理をさせない
```

ビルドは不要。素の ES modules で動く。
